# homebrew-tap

Homebrew formulae for [pi2d](https://github.com/zgs225/pi2d) — the `pi2` web-console daemon for [pi2.nvim](https://github.com/zgs225/pi2.nvim).

## Install

```sh
brew install zgs225/tap/pi2d
```

Or tap once, then install by name:

```sh
brew tap zgs225/tap
brew install pi2d
```

The formula installs `pi2` to `$(brew --prefix)/bin` and the web console to
`$(brew --prefix)/share/pi2d/web/dist` — the layout the binary probes for its own UI,
so no `PI2_STATIC_DIR` is needed.

## After install

```sh
pi2 --version
pi2 doctor                     # node/nvim/pi/plugin/socket/web-dist/unit checks
pi2 install-service --write    # systemd --user unit or launchd agent
pi2 open                       # open the console in a signed-in browser
```

## Upgrade

```sh
brew upgrade pi2d
```

## Formula maintenance

`Formula/pi2d.rb` is generated by the release pipeline in
[zgs225/pi2d](https://github.com/zgs225/pi2d) (`scripts/update-packaging.sh`) and pushed here
whenever a `v*` tag is published. Do not edit it by hand — the next release overwrites it.
